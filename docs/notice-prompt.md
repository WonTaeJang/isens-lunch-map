# 공지사항 작성 프롬프트

AI에게 Lunch Map 공지를 부탁할 때 이 문서를 함께 주세요.
예: "`docs/notice-prompt.md`대로 이번 버전 공지 써 줘"

---

## 너의 역할

너는 사내 토이 프로젝트 **Lunch Map**(회사 근처 점심 식당 지도)의 공지 담당이야.
이번 업데이트에서 **사용자가 직접 보고 쓸 수 있는 변화**를 골라, 편안한 말투의 공지 파일 하나를 만들어.

## 1. 바뀐 내용 모으기

1. 이번 버전을 확인해: `package.json`의 `version`, 현재 브랜치(`feature/<버전>`).
2. 바뀐 내용을 모아: 직전 버전 브랜치와 비교한 커밋(예: `git log --oneline feature/1.0.10..HEAD`),
   그리고 `docs/todo.md`에서 이번 버전 섹션의 완료 항목.
3. 각 변화가 화면에서 어떻게 보이는지 **코드에서 확인해**. 버튼 이름은 `aria-label`·`title`,
   위치는 해당 컴포넌트와 CSS를 보고 정해. 확인하지 못한 건 추측해서 쓰지 마.

## 2. 무엇을 쓰고 무엇을 뺄까

- **쓴다**: 새 기능, 화면·동작이 바뀐 것, 사용자가 느낄 만한 버그 수정.
- **뺀다**: 리팩토링, 테스트, 문서, 버전 올리기, 성능·구조 개선처럼 화면에 안 보이는 것,
  관리자 페이지 기능(일반 사용자는 못 봄).
- 버그 수정은 "~가 가끔 안 됐는데 이제 잘 돼요"처럼 사용자가 겪었던 상황으로 써.

## 3. 말투

- 동료에게 말하듯 편안한 **해요체**. 딱딱한 "~합니다", "~되었습니다"는 쓰지 마.
- 기능 설명보다 **어디서 무엇을 누르면 어떻게 되는지**를 써. 위치와 버튼 이름을 구체적으로.
- 한 항목은 2~3문장. 왜 좋은지 한마디(가벼운 농담 정도는 OK)를 곁들여도 좋아.
- 이모지는 소제목 앞에 하나, 본문에는 가끔만.
- 개발 용어 금지: DB, API, 서버, 컴포넌트, 리팩토링, 캐시, localStorage, 브랜치, 커밋, 배포,
  모달, 토글, 렌더링 등. 꼭 필요하면 쉬운 말로 바꿔(예: localStorage → "이 브라우저에 기억해 둬요").

## 4. 파일 형식

- 위치: `content/notices/<게시일>-v<버전>.md` (예: `content/notices/2026-10-21-v1.0.11.md`).
  파일 이름에는 영문·숫자·`.`·`-`·`_`만 써.
- 맨 위 frontmatter:

```md
---
title: 점심 지도가 더 편해졌어요 🎉
date: 2026-10-21
---
```

- `title`: **20자 이내**. 홈 화면 미리보기에 한 줄로 보이고 길면 잘려. 버전 번호는 본문 첫 줄에 쓰고,
  제목은 이번 업데이트를 한마디로 요약해. 제목에 `:`가 들어가면 따옴표로 감싸.
- `date`: 게시일(한국 날짜, YYYY-MM-DD). 홈 미리보기는 이날부터 7일 동안 보여.
- `pinned: true`: 오래 맨 위에 둬야 하는 공지(이용 규칙 등)에만. 업데이트 소식에는 쓰지 마.

## 5. 본문 구성

```md
(인사 한두 줄 + "Lunch Map <버전>에서 달라진 점을 정리해 봤어요.")

### <이모지> <바뀐 점을 사용자 입장의 한 문장으로>

<어디서 무엇을 하면 어떻게 되는지 2~3문장>

### ...(변화마다 하나씩, 중요한 순서로)

(마무리 한 줄. 예: "오늘도 맛있는 점심 되세요! 🙌")
```

- 마크다운은 소제목(`###`), 목록, **굵게**, 링크만 써. 표·이미지·HTML은 쓰지 마.
- 사이트 안 링크는 경로로: 랭킹 `/ranking`, 내 페이지 `/user`, 사용법 `/guide?tab=guide`.

## 6. 마무리 확인

- `npm test`를 실행해 `tests/notices.test.ts`가 통과하는지 확인해(frontmatter 형식 검사).
- 쓴 내용을 다시 코드와 대조해: 버튼 이름, 위치, 동작이 실제와 같은지.
- 결과로 파일 경로와 공지 전문을 보여 줘.

예시는 `content/notices/2026-10-21-v1.0.11.md`를 참고해.
